# 知识图谱 3D（可点击）

下方 3D 力导向图展示全库页面的交叉引用关系。**点击任意节点会跳转到对应页面**。
数据来自 `wiki/graph.json`（由 Lint 操作根据页面间的链接自动生成）。

<div id="graph" style="height: 80vh; border: 1px solid #ddd; border-radius: 8px;"></div>

<script src="https://unpkg.com/3d-force-graph@1.73.2/dist/3d-force-graph.min.js"></script>
<script>
  const Graph = ForceGraph3D()(document.getElementById('graph'))
    .backgroundColor('#0f1117')
    .nodeLabel('label')
    .nodeAutoColorBy('group')
    .linkColor(() => 'rgba(140,160,200,0.4)')
    .linkDirectionalParticles(2)
    .onNodeClick(node => {
      if (node.link) window.location.href = node.link;
    });

  fetch('../graph.json')
    .then(r => r.ok ? r.json() : Promise.reject(r.status))
    .then(data => Graph.graphData(data))
    .catch(err => {
      document.getElementById('graph').innerHTML =
        '<p style="color:#ccc;padding:1rem">图谱数据暂未生成（需先运行 Lint 生成 wiki/graph.json）。错误：' + err + '</p>';
    });
</script>

> 节点颜色按主题分组；拖拽旋转、滚轮缩放。图谱随内容增长由 Lint 自动刷新。
